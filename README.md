# Sasirangan Banua
### Website Katalog Digital Produk UMKM Khas Kalimantan Selatan

Sasirangan Banua merupakan website katalog digital yang dibuat untuk menampilkan berbagai produk kerajinan Sasirangan, mulai dari kain tradisional, pakaian, hingga aksesoris khas Banjar. Website ini bertujuan memperkenalkan produk pengrajin lokal Banjarmasin melalui media digital.

Proyek ini merupakan bagian dari tugas Praktikum Pemrograman Web 1 di Universitas Islam Kalimantan Muhammad Arsyad Al Banjari.

## Fitur Website

1. **Tampilan Website (Modul 1)**  
   Menggunakan HTML5 dengan struktur elemen semantik untuk menyusun halaman website agar lebih teratur dan mudah dipahami.

2. **Tampilan dan Interaksi (Modul 2)**  
   Menggunakan CSS untuk mengatur warna, tata letak, ukuran, serta desain website agar nyaman dilihat.

3. **Fitur Pencarian dan Filter (Modul 3)**  
   Menyediakan pencarian produk, filter berdasarkan jenis produk, dan formulir kontak dengan validasi JavaScript.

4. **Pengolahan Data dan API (Modul 4)**  
   - Mengambil informasi produk dari file `data/katalog.json`.
   - Menggunakan JavaScript `fetch()` dan `async/await`.
   - Menampilkan informasi jadwal salat Banjarmasin melalui API MyQuran.

## Struktur Folder

- `index.html` — Halaman utama website.
- `kontak.html` — Halaman informasi kontak.
- `data/katalog.json` — Penyimpanan data produk.
- `css/` — Berkas pengaturan tampilan.
- `js/` — Berkas JavaScript.
- `README.md` — Dokumentasi proyek.
